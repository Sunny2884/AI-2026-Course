# 人工智能原理与应用（2026）课程大作业提交说明

## 提交前必看：你怎么能直接 commit 到我的 main 分支啊

你怎么能直接 commit 到我的 main 分支啊？！GitHub 上不是这样！先 fork 本仓库，在自己的 fork 里新建 `submission/group-XX` 分支，把作业放进选题对应的 `group-XX/` 文件夹。代码、说明、结果和 Demo 都准备好，再 push 到你的分支，向本仓库的 `main` 提 Pull Request。PR 里写清楚你们做了什么、怎么复现、结果在哪里；助教提出问题，就在同一个 PR 里修改。不要直接推 main，更不要 force push！文件夹放错、只交一张效果图却找不到代码和结果，我可要请你们回去补齐再来。


本仓库用于课程大作业提交。每组选择一个题目，按下表提交到对应目录；题目任务与评分以课程正式发布的作业说明为准。

## 题目目录

| 题目 | 提交路径 |
| --- | --- |
| 大模型后训练 | PostTraining/group-XX/ |
| RAG（检索增强生成） | RAG/group-XX/ |
| Agent（智能体） | Agent/group-XX/ |
| 图像分割 | ImageSegmentation/group-XX/ |
| 图像生成 | ImageGeneration/group-XX/ |

XX 为课程统一分配的两位组号，且全班唯一。每组仅由组长或指定代表提交，只修改本组目录。

## 文件结构

每组在所选任务目录下创建 `group-XX/` 文件夹，并按以下结构整理作业：

- **代码文件夹**：存放项目源代码。
- **说明文档 `README.md`**：简要介绍项目，说明使用方法并展示结果。
- **其他必要文件**：如配置文件及作业运行所需文件。

例如，Agent 任务的第 5 组提交到 `Agent/group-05/`。

## 分支命名

每组提交作业时，请在自己的 fork 仓库中新建分支，分支名使用组号，例如 `group-05`。分支名应与提交目录中的组号一致。

## 提交流程

1. Fork 本仓库到自己的 GitHub 账号。
2. 在 fork 仓库中新建 `group-XX` 分支。
3. 在所选任务目录下新建 `group-XX/` 文件夹，并放入作业文件。
4. 将更改提交并推送到自己的 fork。
5. 向本仓库的 `main` 分支发起 Pull Request。
6. 等待课程组审核。

## 注意事项

- 请勿直接向本仓库的 `main` 分支提交。
- 每组由组长负责提交。
- 请保持目录结构和文件命名清晰完整，提交前确认文件可用。
