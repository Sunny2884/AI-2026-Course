# 人工智能原理与应用（2026）课程大作业提交说明

## 提交前必看：你怎么能直接 commit 到我的 main 分支啊

你怎么能直接 commit 到我的 main 分支啊？！GitHub 上不是这样！先 fork 本仓库，在自己的 fork 里新建 `submission/group-XX` 分支，把作业放进选题对应的 `group-XX/` 文件夹。代码、说明、结果和 Demo 都准备好，再 push 到你的分支，向本仓库的 `main` 提 Pull Request。PR 里写清楚你们做了什么、怎么复现、结果在哪里；助教提出问题，就在同一个 PR 里修改。不要直接推 main，更不要 force push！文件夹放错、只交一张效果图却找不到代码和结果，我可要请你们回去补齐再来。


本仓库用于课程大作业提交。每组选择一个题目，按下表提交到对应目录；题目任务与评分以课程正式发布的作业说明为准。

## 题目目录

| 题目 | 提交路径 |
| --- | --- |
| 大模型后训练 | PostTraining/group-XX/ |
| RAG（检索增强生成） | RAG/group-XX/ |
| Agent（智能体） | Agent/group-XX/ |

XX 为课程统一分配的两位组号，且全班唯一。每组仅由组长或指定代表提交，只修改本组目录。

## 每组必交内容

在 group-XX/ 下提供项目 README、代码、依赖说明、Demo 和结果材料。组内 README 应说明组员分工、模型与数据来源及许可、环境版本、训练/推理/评测命令、随机种子、硬件与运行时间、权重获取方式、基线与改进方法、结果和已知限制。报告可用 PDF；Demo 可提供录屏或可访问链接。

| 题目 | 结果报告必须覆盖 |
| --- | --- |
| 大模型后训练 | 原始模型、微调、强化学习后训练比较；Macro-F1、模态冲突识别准确率、过度判断率；不确定时的引导提问案例 |
| RAG | 普通 RAG、批判修正、强化学习优化比较；答案 Accuracy、平均修正次数、推理时间；修正过程案例 |
| Agent | 至少两种公开论文来源、去重排序和 Top-k；优化前后相关性/成功率/运行时间比较；总结与综合报告示例 |
| 图像分割 | 基线与改进比较；APS、整体 Mask AP、模型大小、推理速度；RGB-D 输入与预测可视化 |
| 图像生成 | 预训练基线与优化结果比较；非身份特征相似度、身份相似度、图像质量；原图、监督图像和结果展示 |

## 提交流程

1. Fork 本仓库并同步默认分支。
2. 在个人 fork 创建 submission/group-XX 分支，只修改本组目录。
3. 向本仓库默认分支发起 PR，标题格式：[题目] group-XX 作业提交；按 PR 模板填写复现命令、结果摘要和 Demo 链接。
4. 助教在同一个 PR 中反馈；组员在原分支补充，不要重复开 PR。
5. 截止时间及迟交规则以课程组通知为准。截止后修改请在 PR 中说明原因；PR 合并不等于成绩。

## 文件与公开发布

- 不提交原始数据集、大型权重、缓存、虚拟环境或海量输出；提供合法来源和获取说明。大型文件建议外链并提供校验信息。
- 不提交密钥、令牌、密码或个人隐私。人脸数据和结果仅在具备公开授权时上传；论文全文仅提交有权分发的内容。
- 引用第三方模型、数据和代码时注明出处、许可证及修改内容。
- 单个文件建议小于 10 MB，并在 .gitignore 中排除临时文件。

组号、题目或目录需调整时，请先联系课程组。
